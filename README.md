# 🧠⚙️ Entendendo Assembly

> *"Assembly não é sobre decorar instruções. É sobre enxergar o que a máquina realmente está fazendo."*

Bem-vindo(a) ao repositório onde a caixa-preta do processador vira **vidro transparente**! 🔍✨

Se você já olhou para um código Assembly e sentiu aquele misto de "uau" e "socorro", este guia foi feito pra você. Aqui a ideia não é te transformar em um robô que decora `mov`, `add` e `jmp` de cor — é te ensinar a **ler e interpretar** código Assembly com confiança, entendendo o *porquê* por trás de cada linha.

---

## 🎯 Pra quem é esse guia?

- 👨‍💻 Programadores que desejam entender o que o compilador faz "por baixo dos panos"
- 🕵️ Quem quer conseguir ler um `objdump` sem entrar em pânico
- 🧩 Quem gosta de entender sistemas de verdade, camada por camada
- 🐧 Curiosos de plantão que topam uma jornada em Linux, x86-64, ABI System V e sintaxe Intel

Não é necessário nenhum conhecimento prévio de Assembly — só uma boa dose de curiosidade (e talvez um café ☕).
Lembrando que a linguagem C é a linguagem escolhida para usar como referência na programação de alto nível.

---

## 🧭 Como usar este guia

1. Comece pelo [Módulo 01](01-o-que-e-assembly.md) — mesmo que você já saiba um pouco, ele estabelece o vocabulário usado no resto do curso.
2. Cada módulo traz:
   - 📖 Explicação em prosa
   - 📊 Diagramas e tabelas
   - 🧪 Exemplos comentados
   - ✍️ Exercícios (conceituais + aplicados) com **respostas completas**
3. Sempre que possível, os conceitos são conectados com C — porque no fim das contas, é o C que vira Assembly nos seus olhos. 👀

---

## 🛠️ Ambiente de referência

Pra manter tudo consistente ao longo do curso:

- 🐧 **SO:** Linux
- 🧮 **ABI:** System V AMD64
- ✍️ **Sintaxe:** Intel
- 🖥️ **Arquitetura:** x86-64
